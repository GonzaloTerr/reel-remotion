# Pistas de música (rotativas)

Poné acá tus pistas **royalty-free** en `.mp3` (o `.m4a` / `.wav`). El servicio elige **una al azar** en cada render, así cada reel suena distinto.

- Nombres libres, ej: `track1.mp3`, `upbeat.mp3`, `calm.mp3`.
- Recortá las pistas a ~15-20s (el reel dura 15s) para que no haya que descargar de más.
- Si esta carpeta está vacía, el reel se renderiza **sin música** (no rompe).

## Dónde conseguir música gratis (con licencia para redes)
- **Pixabay Music** — https://pixabay.com/music/ (gratis, sin atribución)
- **Uppbeat** — https://uppbeat.io/ (gratis con cuenta)
- **Mixkit** — https://mixkit.co/free-stock-music/
- **YouTube Audio Library** — biblioteca de audio del Studio de YouTube

> Ojo: no uses música comercial con copyright o Instagram/YouTube te van a silenciar o bajar el reel.
